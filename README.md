# HerbiBioS — Cloud Smart Waste Sorting Station

Умная станция автоматической сортировки мусора на базе компьютерного зрения (YOLOv8s + Face Filter), облачного бэкенда и микроконтроллера ESP32-CAM.

---

## Структура проекта

```
garbage/
├── cloud_api/          # Облачный бэкенд для Hugging Face Spaces (FastAPI + YOLOv8s + ZeroGPU)
├── esp32_firmware/     # Прошивка ESP32-CAM (автономный Wi-Fi клиент, сервоприводы)
├── web_frontend/       # Фронтенд панель управления (Vercel)
└── final_product/      # 3D модели корпуса урны и исходные локальные материалы
```

---

## 1. Облачный бэкенд (`cloud_api`)
Развернут на Hugging Face Spaces (ZeroGPU с ускорением на Nvidia A100):
* Детекция мусора (`waste_yolov8s_best.pt`):
  * **БАК 1:** Пластиковые бутылки, пакеты, крышки, тетрапак
  * **БАК 2:** Алюминиевые банки, ключи
  * **БАК 3:** Бумага, картон
* Фильтр лиц (`yolov8n-face.pt`): отсекает лица людей от случайного распознавания.
* REST API: приём фото по `POST /api/frame` и выдача команд на сервоприводы.
* Интерактивная панель управления с живым кадром, статистикой, ползунками углов (0°–180°) и кнопками открытия.

---

## 2. Прошивка ESP32-CAM (`esp32_firmware`)
Находится в одном файле: `esp32_firmware/HerbiBioS_Cloud/HerbiBioS_Cloud.ino`.
* **Подключение:**
  * Серво #1 (Пластик): `GPIO 12`
  * Серво #2 (Металл): `GPIO 13`
  * Серво #3 (Бумага): `GPIO 15`
* Каждые 2.5 секунды отправляет кадр по HTTPS в облако.
* При получении команды поворачивает соответствующий сервопривод на заданный угол на 3 секунды и закрывает.
