# HerbiBioS Web Dashboard (Vercel)

Красивая и быстрая панель управления умной урной, готовая к деплою на Vercel.

## Деплой на Vercel за 1 минуту:
1. Зайдите на [vercel.com](https://vercel.com)
2. Нажмите **Add New... -> Project**
3. Загрузите репозиторий с этой папкой `web_frontend` (или используйте Vercel CLI: команда `vercel deploy` прямо в папке `web_frontend`)
4. Проект развернётся мгновенно и даст вам постоянный адрес (например `https://herbibios.vercel.app`).
5. Откройте сайт, укажите адрес вашего бэкенда с Hugging Face (в поле сверху) и нажмите **Применить**!

## Возможности:
- 🟢 Живой статус Hugging Face AI (Online/Offline + пинг в мс)
- 🟢 Живой статус ESP32-CAM (Online/Offline + время с последнего кадра)
- 📷 Показ последнего кадра с рамками детекции мусора
- ⚡ Кнопки быстрого открытия отсеков на 3 секунды
- 🔧 Ползунки калибровки углов открытия и закрытия для каждого сервопривода (0-180°)
- 💾 Сохранение настроек прямо в облако
